# Himaya Café — Static Vercel Website

A frontend-only, responsive website for Himaya Café (M1–Himaya Enterprises). Built with plain HTML, CSS, and JavaScript. No Laravel, database, backend, authentication, or ordering/payment processing.

## Included
- `index.html` — homepage, story, menu, experience, contact, footer
- `styles.css` — responsive forest-green, cream, brown, and gold styling
- `script.js` — searchable/filterable menu using proposed business menu prices
- `assets/himaya-logo.jpg` — user-supplied official logo

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import it in Vercel as a new project.
3. Set Framework Preset to **Other**, leave Build Command empty, and deploy.
4. Alternatively, drag and drop the folder into a static-site hosting service.

## Before publishing
- Confirm the proposed menu items and prices.
- Replace 'To be announced' with verified location/contact details once available.
- There are no fake contact links or functioning order/payment actions.
- The fonts load from Google Fonts, with local font fallbacks.

## Reference ZIP
The uploaded `coffee-pos.zip` contains a Laravel POS application. This static website is independent from that application, so no `.env` secrets, backend dependencies, or private POS files are included.
